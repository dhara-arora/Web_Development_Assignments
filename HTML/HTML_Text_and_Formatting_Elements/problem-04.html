Mathematics Formula Sheet

A comprehensive reference guide for fundamental algebraic identity expansions, geometric theorems, and mensuration formulas.

Algebra

1. Square of a Sum:
(a + b)2 = a2 + 2ab + b2

2. Square of a Difference:
(a - b)2 = a2 - 2ab + b2

3. Sum of Squares:
a2 + b2 = (a + b)2 - 2ab

4. Quadratic Equation Roots:
For ax2 + bx + c = 0, x1 and x2 are calculated using the discriminant: x1,2 = (-b ± √(b2 - 4ac)) / 2a

5. Sequence Term Formula:
an = a1 + (n - 1)d

Geometry

7. Distance Formula:
d = √((x2 - x1)2 + (y2 - y1)2)

8. Area of a Circle:
Area = πr2

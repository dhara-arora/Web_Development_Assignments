Hardware Terminology & Definitions

RAM
Random Access Memory—the system's high-speed temporary memory used for active application processing.
SSD
Solid State Drive—flash-based permanent storage offering rapid boot times and file read/write performance.
Refresh Rate
Measured in Hertz (Hz), the frequency at which the display panel updates its rendered image per second.
Warranty
The manufacturer's formal commitment covering repair or replacement costs for hardware failures.
